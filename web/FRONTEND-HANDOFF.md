# 治理工作台前端交接

新会话默认选择内置 Global Project，已保存的项目偏好优先恢复。全局页展示全局版本、提案和规则；工作区项目页继续展示真实项目 ID、绑定工作区、本地发布版本、运行配置与加载回执。审查服务（Jev）在「设置」中全局配置一次，所有项目（含 Global Project）共用同一服务，配置状态不随项目切换。项目规则计数来自原始补充候选，全局层独立维护并在发布时组合，不把项目补充计数描述为完整继承结果。权限说明是服务合同中的角色约束，具体操作仍由服务端决定。

规则库展示当前作用域已发布的候选，包括未选用的条目：全局项目显示全局规则，工作区项目显示补充规则。规则矩阵按 ID 去重，在每个领域下分别统计拒绝、需确认、记录和仅建议。前三列只统计按条件处理的规则；点击「仅建议」按规则类型筛选。矩阵统计规则数量，点击后用所选筛选项替换原有筛选。列表搜索、筛选和详情 ID 保存在 hash URL。检查器显示规则说明或指导、选用情况、探测、可选来源及原始记录；运行时加载情况见项目概况。Escape 关闭检查器并尽可能将焦点还给打开按钮，窄屏为底部固定检查器。

规则编辑器按类型展示字段：「按条件处理」用“且”连接各行条件，提供条件预览和命中后处理；「仅建议」直接编辑可加入助手上下文的指导文字。两者共用规则属性与可选来源引用。原始 JSON 与导出保留完整记录，包括仅建议条目按规则格式保存的 `on_hit`；这类条目的 `predicate` 为 `null`，不会产生工具调用裁决。

保留真实登录、项目、内存草稿、校验、提案审批/撤回、版本导出及回滚提案、审计分页、观察日志和模拟 API。提案差异比较**当前已发布原始候选**与提案候选，包括规则作用、字段和本地选用变化。模拟可按当前全局层与项目已发布版本计算，也可在编辑器内直接试跑未提交草稿；结果均为假设评估，不执行或授权动作。观察页只显示服务启动时配置的脱敏来源。全局发布扇出重写已发布项目的激活与 managed 产物，项目版本历史保持不可变；普通适配器仍为 Stage A log-only，显式 managed 路径也不提供同 UID 可信隔离。

助手检测页列出六个助手并执行终端命令探测；已探测到但未接入的 Pi/OpenCode 提供“接入 Amos 插件”按钮：预览展示写入位置与完整内容（OpenCode 只在全局 `opencode.jsonc` 追加 Amos 项并保留其余内容与注释），确认后原子写入，冲突不自动覆盖。安装是用户级一次性动作，插件仍为 Stage A 观察者。

外观默认为浅色，可切换深色/系统和紧凑密度；导航、搜索、表单和检查器提供键盘入口。没有回退数据。权限查询、覆盖率/命中率评估和运行时快照不可用；版本页不提供任意历史版本之间的比较。规则正文和提案可能敏感，避免将截图或本地令牌放入公开证据。
