# 治理工作台前端交接

首页为“项目边界”，展示真实项目 ID、绑定工作区、本地发布版本、发布时间和治理快照摘要。计数来自当前项目 API：存储规则数、按候选 activation 选中的规则数、状态为 pending 的提案数和版本数。运行时加载状态与权限矩阵没有查询 API，显示未知；无安全分数或模拟数据。权限说明是服务合同中的角色约束，具体操作仍由服务端决定。

规则库矩阵覆盖本地已发布候选的全部存储规则，包括未选中项，按规则 ID 去重，按维度和声明的 on_hit 统计，并分别显示确定性和建议性数量；它不是命中次数或运行时评估。点击矩阵会清除其他筛选并按所选维度/声明值筛选列表。列表搜索、筛选和规则详情 ID 保存在 hash URL；检查器展示只读语义、声明检查点、来源/probe 与原始规则。候选激活只描述本地治理快照的选取，声明的 enforcement 不证明部署；运行时状态未知。Escape 关闭检查器并尽可能将焦点还给打开按钮，窄屏为底部固定检查器。

保留真实登录、项目、内存候选、校验、提案审批/撤回、版本导出及回滚提案、审计分页、观察日志和模拟 API。提案差异比较**当前已发布候选**与提案候选，包括字段和本地选取变化；它不是运行时差异。模拟是已发布版本上的假设结果，不执行或授权动作；观察页只显示服务启动时配置的脱敏来源。发布是同 UID 本地 SQLite 治理记录，Stage A 安全策略仍为 log-only，不改变运行时配置或提供可信隔离。

外观默认为浅色，可切换深色/系统和紧凑密度；导航、搜索、表单和检查器提供键盘入口。没有新增后台接口或回退数据。权限查询、覆盖率/命中率评估和运行时快照不可用；版本页不提供任意历史版本之间的比较。规则正文和提案可能敏感，避免将截图或本地令牌放入公开证据。
