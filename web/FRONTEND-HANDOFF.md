# 治理工作台前端交接

新会话默认选择内置 Global Project，已保存的项目偏好优先恢复。全局页展示全局版本、提案和规则；工作区项目页继续展示真实项目 ID、绑定工作区、本地发布版本、运行配置与加载回执。审查服务（Jev）在「设置」中全局配置一次，所有项目（含 Global Project）共用同一服务，配置状态不随项目切换。项目规则计数来自原始补充候选，全局层独立维护并在发布时组合，不把项目补充计数描述为完整继承结果。权限说明是服务合同中的角色约束，具体操作仍由服务端决定。

规则库矩阵覆盖当前作用域已发布原始候选的存储规则，包括未选中项：Global Project 显示全局规则，工作区项目显示补充规则。矩阵按规则 ID 去重，按维度和声明的 on_hit 统计，并分别显示确定性和建议性数量；它不是命中次数或运行时评估。点击矩阵会清除其他筛选并按所选维度/声明值筛选列表。列表搜索、筛选和规则详情 ID 保存在 hash URL；检查器展示只读语义、声明检查点、来源/probe 与原始规则。候选激活只描述该原始候选的选取，声明的 enforcement 不证明部署；运行时状态未知。Escape 关闭检查器并尽可能将焦点还给打开按钮，窄屏为底部固定检查器。

保留真实登录、项目、内存候选、校验、提案审批/撤回、版本导出及回滚提案、审计分页、观察日志和模拟 API。提案差异比较**当前已发布原始候选**与提案候选，包括字段和本地选取变化；它不是组合后的运行时差异。模拟按当前全局层与项目已发布版本计算假设结果，不执行或授权动作；观察页只显示服务启动时配置的脱敏来源。全局发布扇出重写已发布项目的激活与 managed 产物，项目版本历史保持不可变；普通适配器仍为 Stage A log-only，显式 managed 路径也不提供同 UID 可信隔离。

外观默认为浅色，可切换深色/系统和紧凑密度；导航、搜索、表单和检查器提供键盘入口。没有回退数据。权限查询、覆盖率/命中率评估和运行时快照不可用；版本页不提供任意历史版本之间的比较。规则正文和提案可能敏感，避免将截图或本地令牌放入公开证据。
