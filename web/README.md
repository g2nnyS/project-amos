# Amos 本地治理控制台

这是 Amos 的真实治理前端，不是独立的 SaaS 分析演示。界面采用浅色优先、
中性色与蓝色强调的治理工作台；项目、规则、提案、版本、审计、观察与模拟均调用现有
`control-plane/` HTTP API，没有营收、计费、团队或虚构工作区数据。

## 安装与启动

在仓库根目录执行，要求 Node.js 26 与 npm：

```bash
npm ci
npm run console
```

打开服务输出的 `http://127.0.0.1:4310`（或指定端口）。控制台使用真实人类
访问令牌建立会话；按照服务输出的路径在本机编辑器中打开 `human.token`，
粘贴到登录表单。不要把令牌发到聊天、URL 或日志。

前端不单独伪造登录，也不提供代理跨域绕过 Host/Origin/CSRF 的演示服务。
完整启动参数、远程 SSH 隧道、私有状态目录和备份说明见
[本地治理文档](../docs/local-governance.md)。

## 构建与验证

从仓库根目录执行：

```bash
npm run typecheck
npm test
npm run build
npm run console:serve
npm run e2e:smoke # 可选；需本机 Chromium，见 web/e2e/README.md
```

前端源码位于 `web/src/`。根构建先编译服务，再生成 `dist/console/` 的前端
静态资源及封闭清单；服务仅提供清单内的资源，不开放任意文件或 SPA 路径。
页面使用 hash 路由，前端依赖不会进入策略引擎的执行热路径。

## 功能

- 人类会话登录、退出与失效处理；真实项目选择和创建。
- 项目边界、本地快照、规则矩阵、可分享筛选与分层规则检查器。
- 已发布规则库、候选编辑、完整规则与激活集合校验、不可变提案。
- 提案差异、批准与拒绝、撤回、过期与陈旧基准反馈。
- 历史版本、YAML/JSON 下载、生成回滚提案。
- 分页治理审计、启动时配置的脱敏观察日志、已发布策略动作模拟。
- 深色、浅色、系统主题、紧凑密度与移动导航。

只有外观偏好等非敏感界面设置会保存在浏览器。令牌、规则、草稿和治理记录
不作为本地模拟数据库持久化；服务端失败时显示错误或不可用，不填入假数据。

## 安全边界

发布是治理版本发布，不是单次工具执行授权，也不会自动修改 Harness 配置。
安全适配器仍是 Stage A `log-only`，同 UID 本地服务不构成受信隔离。
本次 UI 集成不实现安全自动审查员、受信执行层或运行期强制执行。
